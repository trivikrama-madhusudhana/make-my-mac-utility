# Fictional user facts

Written before answering the first model questions. These are evaluator facts,
not a file supplied to the model. Answer what the model asks using these facts;
delegate engineering choices. Record deviations explicitly.

## Steep

One mug at a time, usually three to five minutes, custom minutes and seconds.
Start, see remaining time, cancel, then start another. When done show a clear
ready state until dismissed; no sound, notifications or history needed. A small
movable panel above ordinary windows, menu-bar Show/Hide/Quit, no Dock, no auto-
startup. Remember an active countdown across quit/relaunch. The clock should keep
counting if the Mac sleeps; a finished timer is ready on wake. Name Steep.
Warm, expressive, readable, a little character; no fake mug illustrations required.
Delegate implementation, minor accessibility and window size to the agent and
the three visual choices. Show focuses the useful next control. Keyboard actions
must work without changing a global setting. Input validation and storage failure
should preserve user input; setup/data live in the fixture for evaluation.

## Frame Names

Choose several JPEG/PNG photos using the normal Mac file chooser. Keep them in
their original folder. Type an inventory code, such as CAM-042. Show before/after
names, alphabetically ordered by original filename: CAM-042-001.jpg and so on,
preserving original extensions. One selected batch, prefix, preview, Rename and
Undo the last successful batch in this session. No scanning, resize, metadata
editing, remote service, history or startup. On any duplicate/occupied target,
show the problem and rename nothing; never overwrite files. Undo should also
check conflicts. Clear outcome and recoverable handling of failures; don't discard
the typed inventory code. Regular compact Mac app with Dock/app switching,
ordinary window, normal level, reopen after close, keyboard-operable controls.
Name Frame Names. Vivid camera-archive personality, strong labels, readable rather
than corporate or gimmicky. Delegate engineering and minor decisions, choose
layout and dimensions through the previews. Only disposable fixture photos.
