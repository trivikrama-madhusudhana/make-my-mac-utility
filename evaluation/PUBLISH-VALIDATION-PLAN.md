# September 14 pre-publication validation

Declared before fresh generation. Evaluate the frozen final skill on this Apple-silicon Mac. This does not simulate another hardware or macOS version.

## Checks and release gate

1. Fresh unfamiliar job: a knitting row counter. Start with everyday consultation, inspect three HTML alternatives, supply a recorded fictional-user choice, build, and test the delivered native app. The evaluator owns GUI operations; the generating agent owns repairs. Check increment, undo, confirmed reset, persistence, failed writes, unreadable state, keyboard interaction, and show/hide/quit where agreed. Preserve original outputs before repairs.
2. Paired blind decision probes: identical realistic scenarios in clean agents, with and without the frozen skill. Judge preservation of intent, resolved versus unresolved approval, existing data protection, integration feasibility, and honest handoff from actual replies. These are response tests, not native-app or statistical reliability scores.
3. Recheck helper behavior, skill metadata, referenced files, portable release contents, and clean extraction. Look for public-package leaks and broken local links.
4. Correct only demonstrated reusable omissions, then rerun affected cases. Keep app defects distinct from skill defects. Refresh installed copies and release hashes only if skill content changes.

Publish recommendation requires no unresolved data-loss or core workflow defect in tested paths, a working new native fixture after any recorded repairs, valid portable artifacts, and explicit evidence limits. Track original versus repaired outcomes. Do not claim a new four-model benchmark or external-Mac validation.

## Fictional knitting user facts

One active knitting project, project name and a nonnegative row count. Increment by one; Undo last successful count change; confirmed reset to zero. Local persistence across quit/relaunch. Failed writes retain previous committed state and the ability to retry. Unreadable existing data is preserved and retried without resetting. Normal covered-by-other-windows accessory panel with menu Show/Hide/Quit; no login startup or global shortcuts. A warm colorful treatment, large row display and primary button; final geometry chosen from preview. No targets, multiple projects, cloud, tracking history or export. Engineering details delegated. The evaluator answers only necessary consultation questions and explicitly approves the selected preview before build.
