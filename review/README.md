# Consultation interfaces for sprint review

Open `index.html`. Each preserved HTML file contains the model’s own three design options for the same fictional Pocket Notes brief. The index identifies the coding agent, model and iteration. Initial snapshots are retained separately from repairs and design revisions.

The files work offline. Controls modify only demo data. HTML appearance is separate from the native app tests. Raw prompts, model responses, build outputs and detailed test evidence remain in `evaluation/runs/` locally.
