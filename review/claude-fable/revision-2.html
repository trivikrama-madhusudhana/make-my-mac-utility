Pocket Notes — three design options

Each frame is a working mock of the same agreed app: one note field, Save, a searchable list with timestamps, and Delete with Undo. Sample notes are fictional. Nothing here writes to disk; saves and failures are simulated locally in this page.

Keyboard in every frame: ⌘↩ (or Ctrl+Enter) saves, Esc in search clears it, Tab reaches each row's Delete button. The "Simulate save failure" switch stands in for a disk error such as a permission problem.
