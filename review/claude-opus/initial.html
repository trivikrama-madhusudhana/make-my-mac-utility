Pocket Notes — three design options (revision r1)

Each panel is shown at its intended size on a stand-in desktop. All three have the same features: one note field, Save, a searchable list with timestamps, and Delete with Undo. This is a preview. Notes are kept in this page's memory, and nothing is written to disk. A browser can't show the native behavior (menu bar, Spaces, other windows covering the panel, focus on Show). That can only be checked on the built app. Try the success test in any option: type a note → Return → search a word from it → Delete → Undo → “Quit & reopen”.

Preview controls (outside the app) Start with:

A — Column 320 × 460Recommended

The note field sits above a tall list in one slim column, which is easy to scan and to keep at the edge of the screen. The trade-off is that the note field is only three lines tall.
